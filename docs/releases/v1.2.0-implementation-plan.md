# Magnexis Maps 1.2.0 — Horizon Implementation Plan

**Codename:** Horizon  
**Target version:** 1.2.0  
**Date:** 2026-10-20

## Audit summary

Existing stack (preserved):
- Monorepo: pnpm + Turborepo
- `apps/web` Next.js + MapLibre
- `services/api` Fastify + Zod + OpenAPI
- PostGIS schema, CT seed places, search, reports, moderation
- Provider adapters for routing/geocoding (no fake results)
- Admin overview, desktop Tauri scaffold, Expo mobile scaffold

Primary UX gap: web UI felt like a developer shell (dense top nav, weak hierarchy, placeholder branding).

## Non-negotiables

- Do not invent routes, traffic, businesses, or verification timestamps.
- Corrections never auto-publish.
- Satellite/hybrid only when licensed styles configured.
- MapLibre RN requires development builds — Expo Go keeps API + GPS + branded UI.
